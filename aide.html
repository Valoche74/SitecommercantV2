Vous êtes client d'un commerce

Ajouter ma carte de fidélité

Scannez le QR code posé sur le comptoir avec l'appareil photo de votre téléphone. Votre carte s'ouvre aussitôt : aucune application à installer, aucun mot de passe à créer. Sur iPhone, vous pouvez ensuite l'ajouter à Apple Wallet en appuyant sur le bouton prévu. Sur Android, ajoutez la page à votre écran d'accueil pour la retrouver en un geste.

Je ne retrouve plus ma carte

  • Sur iPhone : ouvrez l'application Cartes (Wallet), votre carte de fidélité y figure.
  • Sur Android : cherchez le raccourci sur votre écran d'accueil.
  • Dans tous les cas : rescannez le QR du commerce. Vous retomberez sur la même carte, avec vos tampons — ils sont enregistrés, pas perdus.

Ma carte ne s'ouvre pas, ou met longtemps

Vérifiez votre connexion, puis réessayez une fois. Si le problème persiste, écrivez-nous en indiquant le nom du commerce et, si vous l'avez, le numéro inscrit sur votre carte (par exemple FAL-3K9P2A) : c'est ce numéro qui nous permet de la retrouver.

Mes tampons n'ont pas été ajoutés

Signalez-le d'abord au commerçant : c'est lui qui valide les passages, et il peut corriger sur place. Si le compte reste faux, écrivez-nous avec le nom du commerce, la date et le numéro de votre carte.

Utiliser un cadeau ou une offre

Ouvrez votre carte, appuyez sur le cadeau ou sur l'offre : un code s'affiche. Montrez-le au commerçant au moment de payer, il le vérifie sur son téléphone. Une offre a une date de validité : passé cette date, elle disparaît de votre carte et ne peut plus être utilisée.

Ne plus recevoir d'e-mails

Chaque e-mail contient un lien Se désinscrire tout en bas. Un seul clic suffit, l'effet est immédiat et votre carte continue de fonctionner normalement. Vous pouvez aussi nous écrire.

Faire corriger ou effacer mes données

Vous pouvez demander à consulter vos données, à les faire corriger ou effacer. Le commerce chez lequel vous avez pris votre carte est responsable de ces données ; Perify n'est que son prestataire technique. Adressez donc votre demande au commerçant, ou écrivez-nous : nous la lui transmettons et exécutons l'effacement. Vous recevez une réponse sous un mois.

Détail de nos rôles respectifs : données personnelles.

Vous êtes commerçant équipé

Un code est refusé en caisse

L'écran vous dit pourquoi : code déjà utilisé, offre expirée, ou code inconnu. En cas de doute, appelez — l'assistance par téléphone et par e-mail est comprise dans votre abonnement, sans limite de sollicitations raisonnables.

Modifier mes récompenses, mes paliers, mes couleurs

Demandez-le à tout moment, c'est compris. La plupart des changements sont faits dans la journée.

Une panne, un affichage anormal

Appelez, même le soir. Décrivez ce que vous voyez à l'écran : c'est ce qui permet d'aller le plus vite.
